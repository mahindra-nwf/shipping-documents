# Shipping Documents

Standalone Northwest Frozen application foundation. The initial release is a Next.js and TypeScript app designed for Vercel, with Supabase reserved for later authentication and document persistence phases.

## Current phase

Current state: application shell, capture preview, and initial Supabase schema. Authentication and real uploads are not configured.

## Planned boundaries

- Driver workflow: capture and submit shipping paperwork.
- Supervisor workflow: review and manage submitted documents.
- Supabase: dedicated project for this application when persistence is approved.
- Future integrations: versioned authenticated APIs, never direct cross-application database access.
